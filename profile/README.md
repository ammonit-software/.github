# Ammonit Software

Critical systems software still runs on expensive proprietary tools and knowledge locked inside companies. The same problems get solved repeatedly, in isolation.
Ammonit Software takes a different path: open tools anyone can use and maintain when teams that need it.

**Focus areas**

- Testing strategies and frameworks
- Requirements traceability
- Configuration management
- Certification workflows (EN 50128, ISO 26262, DO-178C, IEC 62304, IEC 61508)

---

## Projects

| Project | What it does |
|---------|-------------|
| [ammio](https://github.com/ammonit-software/ammio) | Protocol agnostic test interface for critical-software systems. Talk to any software system in JSON, regardless of its protocol. |
| [ammtest](https://github.com/ammonit-software/ammtest) | Python test framework for critical-software systems. Write, run, and trace system-level tests against any System Under Test (SUT). |
